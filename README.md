# TaskTracker
A command-line tool to track and manage task, built in pure Java with no external dependencies.
Tasks are persisted in a local JSON file.

> Under devolpment

## Features
- [ ] Add, update, and delete tasks
- [ ] Mark tasks as in-progress or done
- [ ] List all tasks, or filter by status
- [ ] Persist tasks to a JSON file


## Built With
- Java (no external libraries)
